# Solitary-Canyon-dynamics
Repository with the final code versions for the manuscript "East Australian Current and submarine canyon interactions promote ageostrophic responses and cross-shelf exchange". This manuscript acts as the first analysis chapter for my PhD.

For the manuscript figures code to run, open source data first needs to be downloaded into a data folder. Data includes satellite SST and geostrophic currents (any from AODN should work, but specific data used is outlined in the manuscript), and SADCP (os75), LADCP, CTD, and hydrochemistry from the voyage CSIRO data trawler page. Additionally, microstructure data will need to be downlaoded.
